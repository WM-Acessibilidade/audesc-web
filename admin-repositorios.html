Formato dos áudios gerados

As prévias e mixagens continuam em WAV de alta qualidade para edição. Na publicação, o Audire converte com FFmpeg para MP3 ou Ogg/Opus, conforme a configuração abaixo.

MP3 64 kbps é o padrão recomendado para máxima compatibilidade. Para narração com fundo musical, 64 ou 96 kbps são recomendados. Ogg/Opus permite também 32 kbps quando a prioridade é máxima economia. Arquivos enviados manualmente continuam preservados no formato original.
